## Overview
This project is an end-to-end data analysis and visualization dashboard built entirely in Microsoft Excel. It consolidates raw macroeconomic data—specifically GDP growth, Inflation, and Unemployment rates—to track Turkey's economic performance over a 10-year period. By applying theoretical economic concepts to real-world data, the dashboard features a calculated Misery Index to provide a holistic view of economic fluctuations and their impact.

## Key Features & Technical Skills Demonstrated
* **Data Wrangling:** Cleansed and standardized raw data extracts using Text to Columns to resolve hidden formatting discrepancies.
* **Relational Data Modeling:** Consolidated disparate datasets across multiple worksheets into a unified Master Table utilizing robust "VLOOKUP" architecture.
* **Advanced Visualization:** Engineered a dual-axis Combo Chart to simultaneously display variables with drastically different scales without losing data fidelity.
* **Interactive UI:** Implemented a Slicer for user-driven, year-over-year dynamic filtering.
* **Automated Logic:** Developed responsive chart titles using nested "IF" and "SUBTOTAL" functions that automatically adapt to user filter selections.

## Macroeconomic Insights
* **The 2020-2021 Pivot:** Captures the 2020 economic slowdown and the subsequent GDP spike in 2021, driven by base effects and expansionary monetary policies.
* **Inflationary Shock:** Visualizes the steep decoupling of growth and price stability, culminating in the sharp inflation peak of 2022.
* **Labor Market Rigidity:** Highlights how the unemployment rate remained relatively sticky (around the 9-13% band) despite extreme volatility in growth and inflation, offering a real-world observation of Okun's Law and Phillips Curve dynamics.
